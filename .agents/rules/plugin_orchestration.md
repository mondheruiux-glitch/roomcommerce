# Plugin & Skill Auto-Orchestration Rules

You must automatically route tasks to the installed plugins and skills based on the active domain, phase, and engineering context without waiting for explicit prompt triggers.

---

## 1. Automated Execution Matrix

### A. Frontend, UI, Design System & Motion
Whenever designing, scaffolding, or styling web or mobile screens:
- **`impeccable`**: Execute for visual audits, typography hierarchy, layout polish, and micro-interactions.
- **`ui-ux-pro-max`** (`design-system`, `ui-styling`, `design`, `brand`): Execute for component specifications, color science, spacing tokens, and Atelier design compliance.
- **`taste-skill`** (`taste-skill`, `minimalist-skill`, `redesign-skill`): Enforce high aesthetic standards, luxury finish, and clean spatial rhythm.
- **`emil-skills`** (`animate`, `animation-performance`, `improve-animations`, `review-animations`): Enforce fluid 60fps spring transitions, Sonner toasts, and interaction choreography.

### B. Engineering Architecture, Testing & Code Quality
Whenever designing interfaces, implementing features, refactoring, or running tests:
- **`agent-skills`**:
  - `spec-driven-development` & `constraint-driven-development`: Ensure strict adherence to PRD and NFR criteria.
  - `test-driven-development`: Write failing tests prior to implementation where appropriate.
  - `incremental-implementation` & `planning-and-task-breakdown`: Deconstruct sprints into verifiable steps.
  - `security-and-hardening`: Apply OWASP, data anonymization, and secret protection standards.
  - `performance-optimization`: Enforce sub-second response times and memory efficiency.
- **`ponytail`** (`ponytail`, `ponytail-audit`, `ponytail-review`, `ponytail-debt`, `ponytail-gain`): Run debt tracking, code smell audits, and maintain clean modular boundaries.

### C. Structural Understanding & Graph Navigation
Whenever inspecting dependencies, complex relationships, or file interactions across the monorepo:
- **`graphify`**: Extract and query the knowledge graph for cross-package and cross-module lineage.
- **`serena`**: Query symbol relationships, references, and semantic navigation across TypeScript and Python services.

### D. Up-to-Date Framework Documentation & External APIs
- **`context7`**: Query the latest official documentation whenever working with modern Next.js 15, NestJS 11, Tailwind v4, Drizzle/Prisma, or Modal SDK to avoid outdated API usage.
- **`supabase`**: Utilize for Supabase schema inspection, auth configurations, migrations, and database administration when Supabase or PostgreSQL services are involved.

---

## 2. Execution Discipline
1. **Zero Guesswork**: Always consult `context7` if a third-party API or library method signature is ambiguous.
2. **Quality First**: Run `ponytail-review` or `impeccable` guidelines prior to marking frontend or backend milestones as done.
3. **Continuity**: Follow the execution milestones mapped in `project road/00_MASTER_EXECUTION_INDEX.md`.
