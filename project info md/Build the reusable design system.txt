## 1. Brand Personality & Core Visual Principles

Project RoomCommerce operates at the intersection of **architectural utility** and **real-world commerce**. The interface must serve as a quiet, precise gallery frame for high-resolution spatial imagery rather than competing with it.

### Brand Personality Attributes
* **Architectural & Grounded:** Rooted in physical materials, structural proportions, and spatial geometry. Avoids ethereal "magic AI" tropes; behaves like an expert architect's working studio.
* **Radically Transparent:** Every visual element maps to a real-world object with physical dimensions, an unvarnished price, and verifiable retailer stock.
* **Effortless & Tactile:** Micro-interactions feel deliberate, responsive, and physical—resembling physical blueprints, fabric swatches, and material spec sheets.

### Core Visual Principles
1. **The Canvas is the Hero:** The room photograph is the primary artifact. Chrome, toolbars, and controls exist on low-contrast structural surfaces that recede, letting interior lighting and materials dominate the viewport.
2. **Precision Over Decoration:** No arbitrary floating shapes, decorative blur blobs, or gratuitous glassmorphism. Visual accents must communicate functional state, spatial coordinates, or inventory availability.
3. **Typographic Decisiveness:** Typography establishes clear hierarchy through structural weight and scale rather than decorative novelty, maintaining high readability on complex photography.
4. **Physicality in Feedback:** Interactive canvas hotspots use subtle, physical pulsing states that indicate coordinate depth without obscuring underlying furniture upholstery or wood grain.

## 3. Comparative Visual Directions & Trade-Offs

We evaluated three coherent visual directions designed specifically for the consumer spatial-commerce workflow.


```

┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              THREE VISUAL DIRECTIONS OVERVIEW                          │
│                                                                                        │
│  [Direction A: Editorial Atelier]    ──► Warm architectural minimalism; tactile,       │
│                                          editorial, premium yet accessible.            │
│                                                                                        │
│  [Direction B: Bauhaus Studio]       ──► Ultra-clean Swiss functionalism; high         │
│                                          contrast, monospace data, pure utility.       │
│                                                                                        │
│  [Direction C: Modern Domestic]      ──► Soft consumer tech; rounded corners, warm     │
│                                          terracotta, friendly and approachable.        │
└────────────────────────────────────────────────────────────────────────────────────────┘

```

### Detailed Direction Evaluation

| Attribute | Direction A: Editorial Atelier *(RECOMMENDED)* | Direction B: Bauhaus Studio | Direction C: Modern Domestic |
| :--- | :--- | :--- | :--- |
| **Concept** | "The Architectural Specifier" | "The Precision Workspace" | "The Friendly Home Companion" |
| **Tone** | Sophisticated, quiet, tactile, trustworthy | Strict, engineering-led, ultra-efficient | Welcoming, casual, accessible, soft |
| **Color Base** | Alabaster (`#F9F8F6`), Charcoal (`#1A1A18`), Warm Gray | Pure White (`#FFFFFF`), Stark Carbon (`#0F0F11`) | Warm Cream (`#FBF9F5`), Deep Bronze (`#2E2724`) |
| **Accent Hue** | Terre Battue (`#B85D3A`) & Sage (`#5B6E58`) | International Klein Blue (`#004BE8`) | Clay Ochre (`#D07C45`) & Soft Sage |
| **Typography** | Editorial Sans (`Plus Jakarta Sans`) + Mono metadata | Swiss Neutral Sans (`Inter` / `PP Neue Montreal`) | Soft Rounded Sans (`Geist` / `Outfit`) |
| **Radii System** | Subtle, tailored ($4\text{px} - 8\text{px}$) | Sharp, architectural ($0\text{px} - 4\text{px}$) | Generous, friendly ($8\text{px} - 16\text{px}$) |
| **Pros** | Elevated aesthetic matches home decor; evokes quality; cushions high-ticket items. | Extreme scannability; appeals to technical users; lowest render overhead. | High consumer warmth; feels non-intimidating to casual shoppers. |
| **Cons** | Requires disciplined photography pairing to avoid feeling overly precious. | Can feel cold, clinical, or like a B2B CAD tool for non-technical movers. | Lacks the high-end polish needed to validate $1,500+ room purchases. |

### Strategic Direction Selection
**Direction A (Editorial Atelier) is recommended.** Furnishing a living space represents a high-emotion, high-capital transaction ($1,000–$3,500 budget). Direction A balances the precision of an architectural drafting tool with the warm editorial confidence of an architectural publication, creating the credibility required for consumers to click outbound purchase links.

### 4.3 Layout Grid & 8pt Spacing Scale

The layout adheres to a strict **8-point linear spatial system**, utilizing a 4pt sub-grid exclusively for icon padding and micro-component alignments.


```

┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                    SPACING SCALE                                       │
├────────────┬──────────┬────────────────────────────────────────────────────────────────┤
│ Token      │ Size     │ Typical Spatial Application                                    │
├────────────┼──────────┼────────────────────────────────────────────────────────────────┤
│ `space-1`  │ 4px      │ Micro-padding, badge vertical padding, focus ring offsets       │
│ `space-2`  │ 8px      │ Icon-to-text spacing, button horizontal padding (compact)       │
│ `space-3`  │ 12px     │ Form input vertical padding, chip spacing                      │
│ `space-4`  │ 16px     │ Default container inner padding, card gaps                     │
│ `space-5`  │ 24px     │ Drawer inner padding, desktop column gutters                   │
│ `space-6`  │ 32px     │ Section spacing, modal header-to-content distance              │
│ `space-8`  │ 48px     │ Major section separation on desktop viewports                  │
│ `space-12` │ 64px     │ Hero container vertical padding                                │
└────────────┴──────────┴────────────────────────────────────────────────────────────────┘

```

#### Grid Specifications
* **Desktop ($\ge 1024\text{px}$):** 12-column grid, $24\text{px}$ gutters, max layout width $1440\text{px}$. The spatial canvas dynamically occupies an $8\text{-column}$ block ($66.6\%$) with a persistent $4\text{-column}$ inspector drawer ($33.3\%$).
* **Tablet ($768\text{px} - 1023\text{px}$):** 8-column grid, $16\text{px}$ gutters. Split canvas with slide-over drawer modal.
* **Mobile ($320\text{px} - 767\text{px}$):** 4-column grid, $16\text{px}$ margins, $12\text{px}$ gutters. Full-viewport canvas with expandable bottom drawer sheet ($60\% - 90\%$ viewport height).

### 4.4 Iconography System

* **Icon Library Standard:** `Lucide Icons` (Custom tuned to $1.75\text{px}$ optical stroke).
* **Grid Basis:** $24 \times 24\text{px}$ bounding box (aligned to the 8pt scale). Compact variants set at $16 \times 16\text{px}$.
* **Optical Weight & Corners:** Clean geometric strokes with slightly rounded caps and joins (`stroke-linecap="round"`, `stroke-linejoin="round"`).
* **Icon Application Rules:**
  * Icons never appear as isolated decoration; every icon represents an actionable control (e.g., `Scan`, `Maximize`, `Share`, `Close`, `Sliders`) or a critical semantic status (`CheckCircle2`, `AlertTriangle`).
  * Canvas hotspot pins use a concentric focal geometry: an outer solid ring ($28\text{px}$) surrounding an inner optical coordinate dot ($8\text{px}$).

### 4.5 Surfaces, Borders, Radii, and Shadows

To preserve an architectural, tangible character, elevation is established primarily through **structural borders and subtle surface value shifts** rather than diffuse multi-layered drop shadows.


```

├───────────────┼──────────────────────────────┼─────────────────────────────────────────┤
│ Base Canvas   │ None                         │ None (Flat #F9F8F6)                     │
│ Card / Panel  │ 1px solid #E6E2DC            │ 0 1px 2px rgba(26, 25, 23, 0.04)        │

│ Modal Dialog  │ 1px solid #1A1917 (10% alpha)│ 0 16px 48px -8px rgba(26, 25, 23, 0.16) │

└───────────────┴──────────────────────────────┴─────────────────────────────────────────┘

```

#### Corner Radii Scale
* **`radius-none` (`0px`):** Image cropping bounds, table cells, full-screen canvas edges.
* **`radius-sm` (`4px`):** Form input fields, budget sliders, specification badges, tooltips.
* **`radius-md` (`8px`):** Product drawer cards, project summary thumbnails, desktop modal dialogs.
* **`radius-lg` (`16px`):** Mobile slide-up sheet top corners.
* **`radius-full` (`9999px`):** Hotspot pins, pill-shaped style toggle chips, primary action buttons.

### 4.6 Imagery & Illustration Direction

* **Room Photography Treatment:** Original room uploads and AI-rendered spaces are presented without color filters, artificial vignettes, or saturation tampering. The viewer must see realistic natural lighting, material finishes, and shadow boundaries.
* **Catalog Product Assets:** Retail product cutouts rendered in the product drawer must use standardized isolated white or neutral-toned backgrounds (`#F9F8F6`), scaled proportionally within uniform $1:1$ bounding containers.
* **Illustration Policy (Strict Elimination of Kitsch):**
  * **Zero 3D Cartoon / Claymorphism Assets:** Strictly forbidden. They destroy credibility for serious homeowners and movers.
  * **Zero Glowing Magic Wands / AI Sparkles:** Replaced by clean architectural drafting glyphs, crosshairs, and spatial grid markers.
  * **Empty State Graphic Treatment:** Technical line-drawn orthographic projections showing room coordinate planes with clean dashed boundaries.

### 4.7 Motion & Interaction Principles

Micro-interactions must feel physical, damped, and purposeful—avoiding whimsical or bouncy game-like physics.


```

┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                 MOTION TIMING & CURVES                                 │
├─────────────────┬──────────┬─────────────────────────────┬─────────────────────────────┤
│ Interaction     │ Duration │ Cubic Bezier Easing         │ Behavioral Intent           │
├─────────────────┼──────────┼─────────────────────────────┼─────────────────────────────┤
│ Pin Hover/Pulse │ 2400ms   │ Ease-in-out (Looping)       │ Gentle beacon signal        │
│ Drawer Slide-In │ 280ms    │ cubic-bezier(0.16, 1, 0.3, 1│ Snappy deceleration (Spring)│
│ State Fade/Swap │ 150ms    │ cubic-bezier(0.4, 0, 0.2, 1)│ Instant visual response     │
│ Progress Bar    │ Linear   │ Matches SSE stream intervals│ Honest pipeline feedback    │
└─────────────────┴──────────┴─────────────────────────────┴─────────────────────────────┘

```

#### Spatial Hotspot Pin States
1. **Idle State:** Solid terracotta core ($8\text{px}$) with an outer semi-transparent white-bordered ring ($24\text{px}$). Subtle looping pulse expands from $24\text{px}$ to $32\text{px}$ with opacity fading from $0.6$ to $0.0$.
2. **Hover State (Desktop):** Ring expands immediately to $32\text{px}$ with high contrast; cursor shifts to `pointer`; mini specification tooltip reveals retailer logo and price within $80\text{ms}$.
3. **Selected State:** Ring locks to $36\text{px}$ with an active charcoal border (`#1A1917`); inner core turns crisp white; corresponding drawer slides in simultaneously.

### 4.9 Accessibility & Contrast Verification (WCAG 2.1 AA)

* **Contrast Ratios:** Every interactive surface and typographic token meets or exceeds WCAG 2.1 AA standards ($4.5:1$ for normal body text, $3.0:1$ for large headings and core functional UI components).
* **Non-Color Dependence:** System states never rely exclusively on color. Stock confirmations combine green tokens (`#2E6945`) with explicit text labels (`"In Stock"`) and checkmark glyphs (`Check`). Out-of-stock items feature clear strikethrough typography and explicit badges.
* **Focus State Mechanics:** All focusable interactive elements feature a high-visibility, dual-layer focus ring (`2px` solid `#1A1917` offset by `2px` white space) that guarantees visibility across dark and light room photography alike.
