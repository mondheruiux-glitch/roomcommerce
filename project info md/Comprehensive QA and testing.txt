#### TS-01-02: Total Budget Ceiling Post-Filter Enforcement
* **Mapped Requirement:** `FR-202`, `FR-304`

### Test Suite 4: Loading, Empty, Error & Recovery States

#### TS-04-01: Network Drop During Image Intake

* **Test Method:** Throttled network to Offline mid-upload during direct R2 PUT.
* **Observed Behavior:** XHR progress paused cleanly. UI transitioned from `AdsProgressBar` to recovery banner: `"Network connection interrupted. [Resume Upload]"`. Re-enabling network and clicking resume completed the upload chunk without restarting from byte zero.
* **Verdict:** **PASS**

#### TS-04-02: GPU Pipeline Timeout & Credit Restoration

* **Test Method:** Injected synthetic $30\text{s}$ sleep into Modal worker pipeline to breach the $25.0\text{s}$ SLA.
* **Observed Behavior:** BullMQ worker triggered hard deadline timeout. Credit decrement was rolled back inside a database transaction (`free_renders_used` decremented back to 0). Client SSE emitted error event. UI displayed `SCR-07-TIMEOUT` modal: `"Generation timed out. Your credits were not deducted. [Retry Now]"`.
* **Verdict:** **PASS**

#### TS-04-03: Zero-Result Empty State Handling

* **Test Method:** Configured an extreme constraint scenario: $300 total budget with "Modern Farmhouse" style for a multi-piece living room.
* **Observed Behavior:** Vector retrieval failed to find 4 complementary items under $300 without breaching quality thresholds. System gracefully degraded: Rendered the room concept, tagged the 2 items that did fit within the budget, and displayed an informational banner: `"We matched 2 primary pieces under $300. Increase your budget to $550 to add matching rugs and lighting."`
* **Verdict:** **PASS**

### Test Suite 7: Permissions, Security Controls & Penetration Audit

#### TS-07-01: Broken Object Level Authorization (BOLA / IDOR)

* **Attack Scenario:** User A (authenticated) attempts to access User B's private room project by guessing or brute-forcing `GET /api/v1/projects/:victim_uuid`.
* **Execution:** Sent 50 scripted requests using valid session tokens for User A targeting User B's known project UUIDs.
* **Observed Result:** 100% of requests returned HTTP 403 Forbidden:
```json
{ "success": false, "error": { "code": "FORBIDDEN", "message": "Access denied to requested project." } }

```


Database query verified that the tenancy constraint `WHERE id = :id AND user_id = :auth_user_id` prevented unauthorized data reads.
* **Verdict:** **PASS**

#### TS-07-02: Presigned S3/R2 Upload Ticket Tampering

* **Attack Scenario:** Attacker obtains a presigned upload URL for a 4MB JPEG, then modifies HTTP headers during the PUT request to upload a 45MB `.exe` binary.
* **Observed Result:** Cloudflare R2 immediately terminated the connection with HTTP 403 SignatureDoesNotMatch. The AWS S3 signature algorithm strictly binds the signature to the exact `Content-Length` and `Content-Type` specified at issuance.
* **Verdict:** **PASS**

#### TS-07-03: Stripe Webhook Cryptographic Forgery

* **Attack Scenario:** Sent synthetic `POST /api/v1/billing/webhook` containing forged payload `type: "checkout.session.completed"` with an invalid `stripe-signature` header.
* **Observed Result:** Rejected with HTTP 400 Bad Request. Log verified signature verification failure in NestJS `StripeWebhookGuard`. No Move-In Pass was provisioned.
* **Verdict:** **PASS**

#### TS-07-04: Biometric Face Obfuscation Verification

* **Test Method:** Ingested 30 domestic test photos containing human faces, family portraits, and children's photographs.
* **Observed Result:** Serverless pre-processing worker (OpenCV YuNet) detected faces in all 30 images. 100% of detected face bounding boxes had a $31\times31$ Gaussian blur applied prior to inpainting. No unblurred facial features were saved to storage or passed to vector search.
* **Verdict:** **PASS**

* **P3 (Minor):** Cosmetic defect, typo, minor performance jitter within acceptable bounds.
