│                             │ Guest        │ Free Tier    │ Holder ($15) │ Admin       │

│ SCR-01: Landing Page        │ Full Access  │ Full Access  │ Full Access  │ Full Access │
│ SCR-03: Workspace Hub       │ View Sample  │ Max 2 Active │ Up to 60     │ Full Access │
│ SCR-04 to 06: Intake Wizard │ 1 Free Trial │ Up to 2 Free │ Unlimited    │ Test Bypass │
│ SCR-08: Interactive Canvas  │ Watermarked  │ Watermarked  │ Clean 4K     │ Clean 4K    │
│ SCR-08A: Product Details    │ 1 Pin Only   │ All Pins     │ All Pins     │ All Pins    │
│ SCR-09: Pass Checkout       │ CTA Target   │ CTA Target   │ Manage State │ Test Mode   │
│ SCR-10: Privacy & Purge     │ Session Only │ Full Access  │ Full Access  │ N/A         │
│ SCR-11 & 12: Admin Consoles │ 404 Blocked  │ 404 Blocked  │ 404 Blocked  │ Full Access │
└─────────────────────────────┴──────────────┴──────────────┴──────────────┴─────────────┘
Anonymous Guest: Permitted to upload 1 photo and view a watermarked low-resolution sample render with 1 clickable pin to demonstrate proof-of-value. Prompted to authenticate via magic link to unlock the remaining pins and save the project.Registered Free User: Granted up to 2 total generations. Renders feature diagonal watermark overlays. Unrestricted access to all product hotspot pins, pricing drawers, and affiliate redirect links.Move-In Pass Holder: Unrestricted generation access within the 30-day window (subject to fair-use ceiling of 60 runs). Renders are full-resolution 4K with watermark removal.System Admin / Operator: Restrictive access to backend catalog sync status, dead-link monitoring, and GPU worker telemetry.5.
