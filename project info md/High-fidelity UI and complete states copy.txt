#### Quality Gate Failure State (`SCR-05-FAIL`)
If the user uploads an unusable asset (e.g., photo of a dog, outdoor garden, pitch-black room, or heavy motion blur):
* **Card Border:** `2px solid var(--ads-color-semantic-danger)` (`#B91C1C`).
* **Error Banner:** Background: `var(--ads-color-semantic-danger-subtle)` (`#FEE2E2`), Text: `var(--ads-color-semantic-danger)`.
* **Message:** `"We couldn't detect clear wall or floor boundaries (Laplacian variance: 38 < 80). Please step back into a corner of the room, turn on overhead lights, and capture both the floor and walls."`
* **CTA:** `[Retake Photo]` (Primary button routes back to `/studio/new/upload`).

#### Timeout / High-Load Recovery Modal (`SCR-07-TIMEOUT`)
If execution exceeds $25.0\text{s}$ due to GPU worker queue backlog:
* Stepper transitions to paused state.
* **Modal Overlay Appears:** Title: `"Generation Taking Longer Than Usual"`. Body: `"Our serverless GPU cluster is currently handling high volume. Your job is safely preserved in queue. You may wait here or have a link emailed to you when processing finishes."`
* **Buttons:** Primary: `[Email Me When Ready]`; Secondary: `[Keep Waiting]`.

# 4. Edge Cases & Defensive UI Design

### 4.1 Extreme Content & String Lengths
* **Overly Long Product Titles:** Product names exceeding 48 characters (e.g., *"Mid-Century Modern 84-Inch Upholstered Sofa with Reversible Chaise in Oatmeal Linen"*) are constrained to a maximum of 2 lines with CSS `line-clamp: 2` and `text-overflow: ellipsis`. The full un-truncated title is accessible via a native HTML `title` tooltip and in the accessible DOM table (`SCR-08B`).
* **High Currency Values:** Budgets up to $10,000 USD format cleanly as tabular figures (`$10,000.00`) using `font-variant-numeric: tabular-nums` to prevent layout jitter during slider adjustment.

### 4.2 Out-of-Stock SKU Handling on the Active Canvas
If an indexed SKU runs out of stock at the retailer after the room generation was rendered:
1. The hotspot pin retains its coordinate on the canvas.
2. In `SCR-08A` (Product Drawer), an amber badge appears: `[Low Stock / Retailer Replacement]`.
3. An alternative, in-stock SKU from the top-3 vector search pool is displayed immediately underneath: `"Alternative Pick: West Elm Harmony Sofa ($1,199.00) — In Stock"`.
4. The user is never directed to a dead 404 retailer page.

### 4.3 Missing Room Imagery / Network Drops
* **Dropzone Upload Drop:** If the network disconnects during the upload of a 15MB HEIC photo, the progress bar pauses, turns amber, and exposes a `[Resume Upload]` retry trigger with exponential backoff (attempting 3 retries before prompting the user).
* **Missing Render Assets:** If a generated render fails to load from Cloudflare R2, the canvas presents an architectural blueprint wireframe fallback with an alert: `"Image asset could not be loaded. [Reload Render]"` without deducting user credits.

### 6.2 Keyboard Focus Trapping & Tab Navigation Rules
1. **Canvas Spatial Navigation:** On `SCR-08`, pressing `Tab` focuses the hotspot pins in logical spatial reading order (top-left coordinate to bottom-right coordinate). Focus ring renders as a dual-layer halo (`2px solid #FFFFFF` inner, `2px solid #1A1917` outer), guaranteeing visibility across light rugs and dark floors.
2. **Modal Dialogs (`SCR-02`, `SCR-09`, `SCR-10`):** Opening any modal locks the background `aria-hidden="true"` and traps keyboard focus within the dialog. Pressing `Escape` closes the modal and immediately returns focus to the trigger button that launched it.
3. **Screen Reader Live Announcements:**
   * Dynamic budget slider changes announce live: `aria-live="polite"` (`"Budget set to $1,500"`).
   * Inference pipeline progress announces phase shifts: `aria-live="polite"` (`"Step 2: Inpainting Japandi Layout complete"`).
